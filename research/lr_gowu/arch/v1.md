# LR-GoWU v1: architecture at commit `4cd3aa0`

Frozen snapshot of what the v1 runs (`runs/lr_test1c_20261027/{a,b}`) executed. Everything is as in
[v2](v2.html) except the items below. v1 ran two arms that differ only in the archive cell key.

## Differences from v2

- **Reachability gate (bug)**: a landmark targeted ≥ 32 times and never reached was skipped *even if it had demos*. Early in training π_R reaches nothing, so every key landmark got gated after its first 32 attempts and was never retried. With no eligible goals, every episode explored from the start state.
- **No ancestor fallback**: an ineligible goal fell back to the group goal or the root, not its nearest eligible ancestor.
- **Doomed gate** needed only 8 handoffs (v2: 16).

## Arms

- **v1-room** (`a`): cell key = (level, room), the plan's default. One landmark per room, so progress inside a room (key collected, ladder climbed) never becomes a goal.
- **v1-xy** (`b`): cell key = (level, room, #keys, x // 16, y // 16), the same as v2. Crippled by the gate bug above.

## Outcome that motivated v2

- v1-room: π_R learned to fetch the key (75% return success), but random exploration from the key never reached a door. Max R = 100.
- v1-xy: 84 landmarks, all in room 1, everything explored from the root. Max R = 100.
