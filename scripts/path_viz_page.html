Montezuma path map

Level 1 as the emulator draws it, with where the agents walk, die and stop. Positions come from RAM bytes the algorithms log for diagnostics only (room = 3, x = 42, y = 43), mapped to pixels by a fit against Joe's sprite (px = x + 3, py = 325 − y). Rebuild: .venv/bin/python scripts/path_viz.py in gowu-montezuma.
