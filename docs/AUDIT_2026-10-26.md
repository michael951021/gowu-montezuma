## Algorithm 1/2: faithful

Outer/inner steps, halt-on-reward, child creation for survivors, all-dead rollback, lex-max (R, U) winner among

## Deviations, most likely to matter first

1. **Particle policy.** Every run so far uses `hold_random` (Remark 5.2 / Fig. 6b ablation, 8 seeds). The
   headline 98,752 number uses the learned zero-target ensemble (ε=0.2). Sec. 6.3 also calls the ablation
   "a single random *policy* sampled once per particle", which is looser than Remark 5.2's "random action".
   Untested here at GPU scale. Ensemble uses Adam, not Muon.
2. **RND learner rate.** Fixed at 8 updates / 1k agent steps (~1 sample per frame); the paper's learner is
   asynchronous and the rate is unstated. Relevant given the U collapse above.
3. **Rollback indexing.** A dead particle keeps its rollout's start node; `ancestor(node, k)` with k∈[1,3]
   goes to that node's parent or above, so the start node itself is never retried. The paper's
   "k generations prior" could mean k=1 = the start node. Ambiguous; ours rolls back one generation further.
4. **RND normaliser warm-up** uses 8 copies of the start frame, not random-agent data (Burda et al.).
   Only affects the first few million frames.
5. **Exploit guard** is a RAM surrogate for App. H's visual detector. Seeds 2/3: 0 rejections; repeated room-5
   rewards in the demos are the two legitimate 300-point doors.

## Root cause of the plateau: an absorbing trap in room 8 (2026-10-26)

15 of 18 seed-runs end with the global winner in room 8 for the last 10% of the run, including every 100M
run (the 43.4k run is absorbed in level 2's room 8). The room-8 key hangs above a rope post; agents jump
from the right ledge onto the post and grab the key (+100) from there.

From the post, nothing gets out of room 8, with or without the key:
- exhaustive 3-segment held-action search (18³ sequences × 12 steps, no sticky): 0 exits;
- jump right (every jump action, 1–15 steps) then walk right: 0 exits; from the ledge the same test gives 195;
- held-action BFS (position-deduplicated): 357 reachable positions, 0 exits;
- cell-archive search (Go-Explore-style cells, sticky 0.25), ~960k steps from each of the key / no-key states:
  355 / 584 cells, all in room 8.

Particles on the post do not die (NOOP/UP/FIRE survive indefinitely), so nothing removes them. With the key
they hold R+100 over everyone, so lex-max (R, U) makes them the group and global winner, and global sync
(Alg. 2 l.9–10) resets every other group into the trap at the next iteration. The RND then trains only on
room-8 frames and U collapses (loss → ~5e-4). This follows from Algorithms 1–2 as written plus the game, so
none of D1–D4 can fix it. How the paper's runs avoid it is not described.
